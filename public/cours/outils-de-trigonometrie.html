2La mesure principale

Quand : un angle fait plusieurs tours, comme 13π/6 ou −415π/11, et tu veux savoir où il tombe sur le cercle.

Ajouter un tour complet ne change pas le point : x et x + 2π, x + 4π, x − 2π… tombent tous au même endroit. Parmi toutes ces mesures, la mesure principale (principal value) est celle qui se trouve dans ]−π ; π]. C'est la convention la plus courante en France ; vérifie que ton cours prend le même intervalle.

La méthode

  1. Compte les tours : divise l'angle par 2π.
  2. Arrondis à l'entier le plus proche : c'est le nombre de tours k à enlever (il peut être négatif).
  3. Enlève ces tours : calcule x − k × 2π, en écrivant 2kπ avec le même dénominateur que x.
  4. Contrôle : le coefficient de π doit être dans ]−1 ; 1]. Sinon, ajoute ou enlève encore un tour.

L'exemple de la vidéo : −415π/11

−415π/112π = −41522 ≈ −18,86 Étape 1 : l'angle contient environ −18,86 tours. k = −19 Étape 2 : l'entier le plus proche de −18,86 est −19. On va donc ajouter 19 tours, soit 38π. −415π11 + 38π = −415π11 + 418π11 = 3π11 Étape 3 : 38π = 418π/11, pour avoir le même dénominateur. 311 ≈ 0,27 ∈ ]−1 ; 1] Étape 4 : contrôle réussi. La mesure principale est 3π/11.

Correction Pourquoi tu as eu besoin de deux étapes

Dans tes notes, la division donne « ≈ 18 ». La vraie valeur est −18,86 : il manquait le signe moins, et 18,86 a été tronqué au lieu d'être arrondi. En ajoutant 18 tours, tu es tombé sur −19π/11 ≈ −1,73π, encore hors de ]−π ; π]. Tu as donc ajouté un tour de plus, et ton résultat final, 3π/11, est juste. Avec l'arrondi à −19, on y arrive en une seule étape.

Outil : calcule une mesure principale, étape par étape

Tape un angle de la forme aπ/b : par exemple -415π/11, 23pi/4 ou 3π. L'outil applique les quatre étapes de la méthode. Fais d'abord le calcul à la main, puis vérifie.

3Même point, ou point opposé ?

Quand : on te donne deux mesures, a et b, et on demande si elles désignent le même point du cercle.

La règle

a et b donnent le même point si leur différence est un nombre entier de tours :

b − a = k × 2π,  avec k ∈ ℤ

En pratique, calcule b − a, divise par 2π, et regarde si le résultat est un entier. Si b − a est un multiple impair de π (π, 3π, 19π…), les deux points sont diamétralement opposés : un nombre entier de tours, plus un demi-tour.

4Lire le cosinus et le sinus sur le cercle

Quand : on te demande la valeur exacte de cos x ou de sin x pour un angle de la table.

La règle

Le point du cercle associé à x a pour coordonnées (cos x ; sin x) : le cosinus se lit sur l'axe horizontal (les abscisses), le sinus sur l'axe vertical (les ordonnées).

Correction Une étiquette de ton dessin

Sur ton grand cercle, l'angle noté « 2π/2 », entre π/2 et 3π/4, est 2π/3. 2π/2 se simplifie en π : c'est le point de gauche.

Deux propriétés qui découlent du dessin

  • −1 ≤ cos x ≤ 1 et −1 ≤ sin x ≤ 1 : le point reste sur un cercle de rayon 1, il ne peut pas sortir du carré [−1 ; 1] × [−1 ; 1]. Une équation comme cos x = 2 n'a donc aucune solution.
  • cos²x + sin²x = 1 : c'est le théorème de Pythagore dans le triangle ci-dessous. On s'en servira à l'outil 9.

Un angle hors de la table : π/7

Personne ne connaît cos(π/7) par cœur. La vidéo l'appelle simplement a, et sin(π/7) = b. On peut pourtant en déduire d'autres valeurs : 6π/7 = π − π/7 est le symétrique de π/7 par rapport à l'axe vertical. Il est à la même hauteur, mais de l'autre côté :

cos(6π7) = −a     sin(6π7) = b

C'est déjà le raisonnement des angles associés, que tu retrouveras à l'outil 7. Pour apprendre la table elle-même, ton jeu Cercle trigo par cœur est fait pour ça.

5Résoudre une équation

Quand : l'équation se ramène à cos x = c ou sin x = c, avec c une valeur de la table.

La méthode

  1. Fais un croquis du cercle trigonométrique. Tes notes disent : « tout le temps le faire ». Elles ont raison.
  2. Isole le cosinus ou le sinus, comme l'inconnue d'une équation du premier degré.
  3. Trace la droite : pour cos x = c, la droite verticale d'abscisse c ; pour sin x = c, la droite horizontale d'ordonnée c.
  4. Lis les points d'intersection avec le cercle : il y en a deux, un seul, ou aucun.
  5. Écris S dans l'intervalle demandé, puis sur ℝ en ajoutant 2kπ à chaque solution.

Exemple 1 : cos x = −1/2

La droite coupe le cercle en 2π/3 et en −2π/3. Pour écrire −2π/3 dans [0 ; 2π[, on ajoute un tour :

−2π3 + 2π = −2π3 + 6π3 = 4π3

Sur ]−π ; π] : S = {−2π/3 ; 2π/3}

Sur [0 ; 2π[ : S = {2π/3 ; 4π/3}

Sur ℝ : S = {2π/3 + 2kπ ; k ∈ ℤ} ∪ {−2π/3 + 2kπ ; k ∈ ℤ}

Tes notes s'arrêtent à la conversion en 4π/3 : les trois ensembles de solutions sont Complément.

Exemple 2 : 2 sin x + √3 = 0

2 sin x + √3 = 0 ⇔2 sin x = −√3 ⇔sin x = −√32 On isole le sinus.

Sur [−π ; π[ : S = {−2π/3 ; −π/3}

Sur [0 ; 2π[ : S = {4π/3 ; 5π/3}, car −π/3 + 6π/3 = 5π/3 et −2π/3 + 6π/3 = 4π/3

Sur ℝ : S = {−π/3 + 2kπ ; k ∈ ℤ} ∪ {−2π/3 + 2kπ ; k ∈ ℤ}

Exemple 3 : 2 cos x + 2 = 0

2 cos x + 2 = 0 ⇔ 2 cos x = −2 ⇔ cos x = −1

Sur [−π ; π[ : S = {−π}

Sur [0 ; 2π[ : S = {π}

Sur ℝ : S = {π + 2kπ ; k ∈ ℤ}

Complément Écrire les solutions sur ℝ

Tes notes écrivent « π + k × 2π ». Sur une copie, écris l'ensemble en entier : S = {π + 2kπ ; k ∈ ℤ}. Le « k ∈ ℤ » est obligatoire : k est un nombre de tours, et il peut être négatif.

Complément Lis bien les crochets de l'énoncé

6Résoudre une inéquation

Quand : l'inégalité se ramène à cos x ≤ c, sin x > c, etc.

La méthode

  1. Isole le cosinus ou le sinus. Si tu divises par un nombre négatif, le sens de l'inégalité change (dans tes notes : « je switch mon inégalité »).
  2. Croquis et droite, comme pour une équation.
  3. Colorie l'arc des solutions : à gauche de la droite pour cos x ≤ c, à droite pour cos x ≥ c, en dessous pour sin x ≤ c, au-dessus pour sin x ≥ c.
  4. Les extrémités sont incluses (point plein) avec ≤ ou ≥, exclues (point vide) avec < ou >.
  5. Écris l'intervalle en parcourant l'arc dans le sens trigonométrique, depuis le début de l'intervalle demandé. Si l'arc passe par ce point de départ (−π ou 0), il se coupe en deux morceaux : on écrit une réunion ∪.

cos x ≤ 1/2

Sur [−π ; π[ : S = [−π ; −π/3] ∪ [π/3 ; π[

Sur [0 ; 2π[ : S = [π/3 ; 5π/3]

Sur [−π ; π[, l'arc passe par −π, le début de l'intervalle : deux morceaux. Sur [0 ; 2π[, il ne passe pas par 0 : un seul.

2 cos x + √2 > 0

2 cos x > −√2 ⇔ cos x > −√22

Sur [−π ; π[ : S = ]−3π/4 ; 3π/4[

Sur [0 ; 2π[ : S = [0 ; 3π/4[ ∪ ]5π/4 ; 2π[

−2 sin x + 1 > 0

−2 sin x + 1 > 0 ⇔−2 sin x > −1 On soustrait 1 : le sens ne change pas. ⇔sin x < −1−2 = 12 On divise par −2, négatif : le sens change.

Sur [−π ; π[ : S = [−π ; π/6[ ∪ ]5π/6 ; π[

Sur [0 ; 2π[ : S = [0 ; π/6[ ∪ ]5π/6 ; 2π[

√3 + 2 sin x > 0

2 sin x > −√3 ⇔ sin x > −√32 On divise par 2, positif : le sens ne change pas.

Sur [−π ; π[ : S = [−π ; −2π/3[ ∪ ]−π/3 ; π[

Sur [0 ; 2π[ : S = [0 ; 4π/3[ ∪ ]5π/3 ; 2π[

Correction Une étape par ligne

Dans tes notes, tu écris la division sous le membre de droite, sur la même ligne : « −2 sin(x) < −1 », avec −2 en dessous. Lue seule, la ligne « −2 sin x < −1 » est fausse, puisque −2 sin x > −1. Même chose pour « 2 sin(x) > −√3/2 ». Sur une copie, écris chaque étape sur sa propre ligne : d'abord −2 sin x > −1, puis, en divisant par −2, sin x < 1/2. Tes ensembles de solutions sont tous justes.

7Les angles associés (tes « angles cousins »)

Quand : une expression contient cos(π − x), sin(x + π/2), cos(−x)… et il faut la simplifier, ou se ramener à un angle de la table.

Le nom officiel est angles associés (related angles). Ta vidéo donne le meilleur conseil possible : pas besoin de les apprendre par cœur. On fait un croquis et on les déduit.

La méthode

  1. Place x au hasard dans le premier quart de tour.
  2. Place l'angle associé : −x, π − x, x + π…
  3. Compare les projections sur les deux axes : même valeur, ou valeur opposée ?

8Les trois types d'équations

Quand : les deux membres de l'équation sont des cosinus ou des sinus d'expressions en x, comme cos(2x) = cos(x + π).

Type 1 : cos A = cos B

cos A = cos B  ⇔  A = B + 2kπ  ou  A = −B + 2kπ,  k ∈ ℤ

Deux angles ont le même cosinus s'ils sont au même point, ou symétriques par rapport à l'axe horizontal (même abscisse).

Exemple : cos(2x) = cos(x + π). On écrit les deux cas, et on résout chacun comme une équation du premier degré :

2x = x + π + 2kπ ⇔2x − x = π + 2kπ ⇔x = π + 2kπ
2x = −(x + π) + 2kπ ⇔3x = −π + 2kπ ⇔x = −π3 + 2kπ3 On divise tout par 3, y compris 2kπ.

Toutes les solutions sur ℝ : S = {π + 2kπ ; k ∈ ℤ} ∪ {−π/3 + 2kπ/3 ; k ∈ ℤ}.

Les solutions dans un intervalle

Complément Attention au total : π apparaît deux fois

π est dans les deux colonnes (k = 0 à gauche, k = 2 à droite). Un ensemble ne contient pas deux fois le même élément : S = {π/3 ; π ; 5π/3}, trois solutions, et non 1 + 3 = 4. On peut vérifier π dans l'équation : cos(2π) = 1 et cos(π + π) = cos(2π) = 1.

Pourquoi s'arrêter ? Dans chaque famille, x augmente quand k augmente. Dès qu'une valeur dépasse 2π, toutes les suivantes aussi ; dès qu'une valeur est sous 0, toutes les précédentes aussi. Écris-le en une phrase sur ta copie : c'est ce qui prouve que tu n'as oublié aucune solution.

Complément Le raccourci : une inéquation sur k

Au lieu d'essayer les k un par un, on écrit que x est dans l'intervalle, et on isole k :

0 ≤ −π3 + 2kπ3 < 2π ⇔0 ≤ −1 + 2k < 6 On multiplie tout par 3/π, positif : le sens ne change pas. ⇔12 ≤ k < 72 k est un entier, donc k ∈ {1 ; 2 ; 3} : trois solutions, π/3, π et 5π/3.

Type 2 : sin A = sin B

sin A = sin B  ⇔  A = B + 2kπ  ou  A = π − B + 2kπ,  k ∈ ℤ

Deux angles ont le même sinus s'ils sont au même point, ou symétriques par rapport à l'axe vertical (même ordonnée).

Exemple : sin(3x + π/2) = sin(x − π).

3x + π2 = x − π + 2kπ ⇔2x = −π − π2 + 2kπ = −3π2 + 2kπ ⇔x = −3π4 + kπ On divise tout par 2 : 2kπ devient kπ.
3x + π2 = π − (x − π) + 2kπ ⇔4x = 2π − π2 + 2kπ = 3π2 + 2kπ ⇔x = 3π8 + kπ2 On divise tout par 4.

Correction Le « + 2kπ » qui disparaît

Dans tes notes, une ligne dit « 4x = 3π/2 », sans « + k2π ». La ligne suivante le remet, donc ton résultat est juste. Mais sur une copie, chaque ligne doit être vraie : sans 2kπ, « 4x = 3π/2 » n'a qu'une solution.

Type 3 : cos a = sin b

On transforme l'un en l'autre pour revenir au type 1 ou au type 2. Le conseil de la vidéo : transformer le sinus en cosinus, avec l'angle associé π/2 − x de l'outil 7 :

cos a = sin b ⇔cos a = cos(π2 − b) Car sin b = cos(π/2 − b). ⇔a = π2 − b + 2kπ  ou  a = −π2 + b + 2kπ C'est le type 1, avec B = π/2 − b. Le second cas vient de −(π/2 − b) = −π/2 + b.

9Du sinus au cosinus

Quand : on te donne sin x (ou cos x) et l'intervalle où se trouve x, et on demande l'autre.

La méthode

  1. Remplace la valeur connue dans sin²x + cos²x = 1, et calcule cos²x.
  2. Prends la racine : il y a deux candidats, √(…) et −√(…).
  3. Le croquis de l'intervalle donne le signe, et donc le bon candidat.

Exemple : sin x = 1/3, avec x ∈ [π/2 ; π].

(13)² + cos²x = 1 ⇔cos²x = 1 − 19 = 89 ⇔cos x = √8/9  ou  cos x = −√8/9 Deux candidats. Sur [π/2 ; π], le point est à gauche de l'axe vertical : le cosinus est négatif. cos x = −√8/9 = −√83 = −2√23 √(a/b) = √a/√b, puis √8 = √4 × √2 = 2√2.

Correction Finis le calcul

Tes notes s'arrêtent à −√(8/9). Ce n'est pas une forme finie : il reste une fraction sous la racine. La forme attendue est −2√2/3. Ton cours Fractions et racines explique les deux règles utilisées (sections 2.2 et 2.4).

10Formules d'addition et de duplication

Quand : l'angle n'est pas dans la table mais s'écrit comme une somme, une différence ou un double d'angles connus, ou il faut développer cos(a + b).

Les formules d'addition

cos(a + b) = cos a cos b − sin a sin b

cos(a − b) = cos a cos b + sin a sin b

sin(a + b) = sin a cos b + cos a sin b

sin(a − b) = sin a cos b − cos a sin b

Pour s'en souvenir : le cosinus garde le même type de produit (cos cos, puis sin sin) et change le signe ; le sinus mélange (sin cos, puis cos sin) et garde le signe.

Les formules de duplication

Elles se déduisent des formules d'addition, avec b = a. C'est ce que fait la vidéo :

cos(2a) = cos(a + a) = cos a cos a − sin a sin a =cos²a − sin²a =cos²a − (1 − cos²a) = 2cos²a − 1 On remplace sin²a par 1 − cos²a, grâce à cos²a + sin²a = 1. =1 − 2sin²a Complément En remplaçant plutôt cos²a par 1 − sin²a. Cette forme sert pour sin(π/8). sin(2a) = sin(a + a) = sin a cos a + cos a sin a = 2 sin a cos a

Application 1 : cos(π/12)

π/12 n'est pas dans la table, mais c'est la différence de deux angles connus : π/3 − π/4 = 4π/12 − 3π/12 = π/12.

cos(π12) = cos(π3 − π4) =cos π3 cos π4 + sin π3 sin π4 La formule de cos(a − b). =12 × √22 + √32 × √22 =√2 + √64 ≈ 0,966 √3 × √2 = √6 : la règle du produit des racines.

11L'équation finale : cos x + sin x = 1

Quand : l'équation mélange cos x et sin x, et aucun des trois types ne s'applique directement.

La méthode de la vidéo : tout mettre au carré

(cos x + sin x)² = 1² cos²x + 2 cos x sin x + sin²x = 1 L'identité remarquable (a + b)² = a² + 2ab + b². 1 + sin(2x) = 1 cos²x + sin²x = 1 et 2 sin x cos x = sin(2x). sin(2x) = 0 2x = 2kπ  ou  2x = π + 2kπ x = kπ  ou  x = π2 + kπ

π et 3π/2 vérifient l'équation au carré, mais pas cos x + sin x = 1. La raison est logique : si A = B, alors A² = B², mais la réciproque est fausse. A² = B² veut dire A = B ou A = −B. Le carré a ajouté les solutions de cos x + sin x = −1. Le passage au carré, la première ligne du calcul, est une implication ⇒, pas une équivalence ⇔ (ton cours de logique, partie 5).

Les vraies solutions : S = {2kπ ; k ∈ ℤ} ∪ {π/2 + 2kπ ; k ∈ ℤ}.

La règle : après avoir élevé au carré, on vérifie chaque solution dans l'équation de départ, et on retire celles qui ne marchent pas. Soit la vidéo l'a fait et ça manque dans tes notes, soit elle l'a sauté. Sur ta copie, cette vérification est obligatoire.

Complément Une seconde méthode, sans piège

Avec la formule de cos(a − b) et b = π/4 :

√2 cos(x − π4) = √2 (cos x cos π4 + sin x sin π4) =√2 × √22 (cos x + sin x) = cos x + sin x √2 × √2/2 = 2/2 = 1.

L'équation devient donc une équation de type 1, où chaque étape est une équivalence :

cos x + sin x = 1 ⇔cos(x − π4) = 1√2 = √22 = cos π4 ⇔x − π4 = π4 + 2kπ  ou  x − π4 = −π4 + 2kπ ⇔x = π2 + 2kπ  ou  x = 2kπ

Même résultat, et aucune vérification n'est nécessaire, puisqu'on n'a jamais quitté les ⇔.
